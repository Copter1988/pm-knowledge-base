## 1 导言

### 1.1 编写目的
本文档完整界定「天平校验视频分析系统」的软件需求，覆盖业务需求、用户需求、功能需求、非功能需求四个层次，以及接口需求、数据需求和约束假设，作为后续 WBS 分解、进度计划、成本估算、风险管理的依据。本课程设计交付物为**项目管理文档 + 可运行代码项目**，本文档是两者的共同输入。

预期读者：项目组成员、指导教师、评审。

### 1.2 项目背景

**产品名称**：天平校验视频分析系统

| 角色 | 主体 |
|---|---|
| 任务提出者（甲方/需方） | 检验科室（电子天平的实际使用者） |
| 开发者（乙方/供方） | 第 1 组项目团队 |
| 用户 | 管理员、检验人员、复核确认人员 |
| 与其他系统的关系 | 与 LIMS（实验室信息管理系统）预留数据对接，不替代 LIMS |

电子天平每天使用前需做「外部校验」：用 3 个标准砝码、每个砝码称 3 次（共 9 次称量），每次示值须在标称值 ±0.05% 以内，当天方可使用。现有校验依赖人工手写纸质记录，存在工作量大、信息孤岛、难以回溯等问题。

本项目用「手机录像 + 视觉识别（辅助录入）+ 人工核对」的方式，自动完成校验过程的记录、判定与归档。项目介绍 PPT 中曾提出「语音交互」，经需求确认，语音识别的信息可由称量顺序、天平主数据、视频时间戳及文字备注替代，故**语音交互不实做**（见 §3.3.3）。

### 1.3 术语定义

| 术语 | 含义 |
|---|---|
| 天平 | 电子天平（称量仪器） |
| 砝码 | 标准砝码（已知标称质量的标准件） |
| 外部校验 | 用标准砝码称量比对、判定天平是否合格 |
| 单量程 / 双量程 | 天平只有一个量程 / 有高低两个量程 |
| 分度值（量程精度） | 天平显示的最小刻度，决定示值显示到几位小数 |
| 限度 | 示值合格范围，= 砝码标称值 ± 标称值×0.05% |
| 复核确认 | 复核人员对检验人员提交的记录逐条做最终确认 |
| 作废 | 记录因录错/操作失误而失效（保留在库、可查，不参与统计） |

## 2 任务概述

### 2.1 系统定义

#### 2.1.1 项目来源与背景

**现有校验流程（PPT 第 7–8 页）**
1. 多名检验人员轮班，每人负责一周，独立操作与记录；
2. 称重操作共 10 步：等待稳定→手动清零→开称重仓→放砝码→关仓→等约 3s 稳定→按打印/上传键记录→开仓→取砝码→关仓；
3. 3 个砝码按**标称值从大到小**依次称量，每个砝码称 3 次，共 9 次；
4. 9 次称量后，手写记录 + 留证据（天平自带打印机打印贴纸 / 通过 LIMS 上传数值）；
5. 保存纸质记录表。

**现有痛点（PPT 第 9 页）**
1. **工作量大**：每天待校验天平超过 20 台时，检验员测试与记录量激增；且间隔约 3 个月才轮到自己，记录表修订、操作遗忘都会导致记录错误。
2. **信息孤岛**：不同品牌/规格天平留存方式不同（打印/上传不一），新购置天平还存在通讯协议差异。
3. **纸质记录难回溯**：记录越积越多，要么没法回溯检查，要么发现错误无法纠错。

#### 2.1.2 系统目标
将天平日常校验从「纸质手写」升级为「电子化记录」，核心价值为：
- **留痕可回溯**：校验过程录像留证，识别值与人工确认值的改动均留痕；
- **自动判定**：按 ±0.05% 规则自动判定每次校验是否通过；
- **记录电子化**：可查询、可导出 PDF、可生成称重值曲线图。

> 说明：视觉识别（OCR）在本系统中的定位是**辅助录入**——预填读数、减少手工录入，最终数值以人工核对确认为准，不是全自动分析。

#### 2.1.3 系统整体结构与各组成部分结构

系统为**内网 Web 应用**，整体结构按功能划分为 8 个模块：

| 功能模块 | 说明 |
|---|---|
| 用户登录与权限管理 | 三类角色登录鉴权；管理员增删检验/复核人员、重置密码 |
| 视频导入与视觉识别 | 视频上传；二维码识别人员/天平；OCR 预填 9 次示值与时间 |
| 校验记录管理 | 新建校验、核对（改值留痕/补录）、勾选前置条件、备注、提交、作废 |
| 校验判定引擎 | 限度实时计算（±0.05%）、9 次示值逐次判定、前置条件一票否决 |
| 复核确认 | 逐条/批量复核确认、打回；确认后数据锁定 |
| 记录查询与统计 | 按天平+日期段查询、称重值曲线图、复核通过记录导出 PDF |
| 天平/砝码与模板维护 | 天平主数据、砝码盒、校验频次 CRUD；记录模板设计修改 |
| 留痕与审计日志 | 识别值改动留痕、五类操作审计、视频 7 天保留、每日备份 |

#### 2.1.4 系统范围

**做（in scope）**：
- 校验视频导入与视觉识别（二维码识别 + 示值 OCR 预填）；
- 人员 / 天平二维码识别与匹配；
- 校验记录管理（录入、核对、提交、复核、作废、查询、导出）；
- 检验人员 / 复核确认人员 / 管理员三类角色及权限；
- 天平与砝码信息、校验模板的维护。

**不做（out of scope）**：
- 天平的内部校正 / 自动校准本身（系统只管外部校验记录）；
- LIMS 系统的开发（系统只做数据对接/预留）；
- 视频识别 AI 模型的训练（OCR 采用本地开源模型/预留接口，不做自研训练）；
- 天平可用状态的管理（系统只记录校验结果"通过/不通过"，不合格后的报修、停用等处置在线下进行）。

### 2.2 应用环境

| 维度 | 说明 |
|---|---|
| 设备环境 | 服务器（内网）；用户经办公电脑浏览器或手机浏览器访问 |
| 硬件环境 | 内网服务器 1 台；客户端为普通办公电脑/手机，无需专用硬件 |
| 软件环境 | 服务端 Java；数据库 MySQL；客户端为浏览器（简单前端） |
| 网络环境 | 内网（局域网）运行，不暴露公网 |
| 用户操作模式 | 检验人员「导入视频 → 核对 → 提交」；复核确认人员「待复核列表 → 确认/打回」；管理员「人员账号维护」 |
| 视频采集方式 | 手机拍摄校验全过程，当天录制、当天上传（电脑或手机上传） |

### 2.3 假定和约束

| 类别 | 内容 |
|---|---|
| 经费限制 | 无硬件采购预算，OCR 采用开源/预留接口，不购买商业识别服务 |
| 开发期限 | 12 月 19 日提交截止（上传百度网盘，设永久有效） |
| 人员 | 开发方 2 人组；使用方为管理员 1 人、检验人员 2 人、复核确认人员 1 人 |
| 最终用户特点 | 检验/复核人员非计算机专业人员，界面须简单、步骤少（≤3 步完成核心操作） |
| 环境假设 | 手机拍摄的视频画面清晰、人员/天平身份卡可识读，天平示值可见；示值需在**稳定后**读取（连续 1~2 秒不跳动），部分天平以示值颜色变化（灰→深）指示稳定；待机时显示 0.000g 一类零值，省电模式下屏幕变暗。天平原屏可能显示 g 或 mg，系统须保留原数值和单位，并将限度与判定统一换算为 g——故 OCR 仅作预填、最终以人工核对为准 |

#### 3.1.3 各角色功能详述

**管理员**
- 登录；
- 增加 / 删减检验人员、复核确认人员；
- 重置密码。

**检验人员**
- 登录；
- 导入校验视频（当天录制、当天上传；电脑或手机上传）；
- 查看视觉识别结果（人员二维码 / 天平二维码 / 9 次示值预填 / 时间）；
- 人工勾选校验前置条件：**清洁、水平、内部校正是否通过**（内部校正可取"是/否/NA"）；
- **核对确认**：核对"系统读入的示值与视频/照片中天平显示一致"，识别值存疑时直接人工改（改动留痕），识别不到时人工补录；
- 处理系统提示：量程 / 精度或读数位数不符时，回看视频确认后勾选"已确认"；
- 填写备注（默认"无"；出现较大误差时系统已自动预填、人可删改）；
- 确认并提交；提交后仍可改备注，复核确认后不可改（示值始终不可改，需改则重录作废）；
- 按天平编号、日期段查询校验记录（默认展示已复核记录，已作废记录可另行调出）；
- 查看某天平称重值曲线图（横轴为示值序号 1~9）。

**复核确认人员**
- 登录；
- **逐条或批量复核确认**：查看待复核记录（读数表、称重值曲线、视频回放、前置条件与备注），确认或打回；
- 确定天平校验频次（写入天平主数据，仅作参考、不主动提醒）；
- 检查"较大误差"备注是否填写（系统按 1% 自动标记并预填、人可删改）；
- 按天平编号、日期段查询所有校验记录、看曲线图；
- 按日期/日期段导出复核通过的记录（PDF，可打印）；
- 设计 / 修改校验记录模板；
- 增删改天平信息及其校验砝码、判定要求。

#### 3.1.4 系统自动处理能力

| 能力 | 说明 |
|---|---|
| 自动认字 | 从校验视频中读出人员卡片、天平卡片、天平量程与精度信息、9 次称重读数（按称量顺序归组至 L1/L2/L3，双量程同样）及每次读数时间 |
| 自动查对 | 视频中的拍摄人员与登录账号核对；天平卡片与已登记的天平资料核对 |
| 自动判定 | 按标称值 ±0.05% 算出每次读数的允许范围并逐次判定；清洁、水平、内部校正任一项不满足直接判不通过 |
| 自动提示 | 提示四类问题：拍摄人员与登录账号不一致、天平未登记或选错天平、量程或精度对不上、读数位数不对（可一键跳到视频对应时间） |
| 自动标记较大误差 | 读数偏差超过标称值 1% 时自动在备注写明偏差并提示"必要时报修"（系统预填，人可删改） |
| 自动算表 | 自动计算限度、自动生成记录号、自动汇总判定结论 |
| 自动归档 | 记录与视频绑定；视频保留 7 天，可自行删除，删除留痕 |
| 自动留痕 | 识别值被人工修改时记录"原值 → 改后值"；提交、复核、一票否决、作废等操作全部留档 |
| 自动出图 | 按天平编号生成 L1/L2/L3 三个称重值趋势图（每组连接最大值/最小值）；复核通过的记录可导出 PDF、可打印 |

#### 3.1.5 核心业务规则（校验判定规则）
1. **限度实时计算**：每个砝码的合格限度 = `标称值 ± 标称值 × 0.05%`，由系统实时计算，**不得引用表格中写死的限度值**（xlsx 中限度栏与标称值不一致，属模板残留，不可信）。
2. **逐示值判定**：9 次示值逐个判定，任一示值超出限度 → 本次校验**不通过**。
3. **前置条件一票否决**：清洁、水平、内部校正三项中任一项不通过 → 本次校验直接判定不通过，示值不再判定。
4. **示值归组**：砝码按标称值从大到小称量（L1→L2→L3），第 1~3 次示值归属 L1、第 4~6 次归属 L2、第 7~9 次归属 L3，按顺序自动归组，不依赖语音口述；**单/双量程天平均按此顺序归组**，量程只决定各读数位数（见规则 5），不参与归组。
5. **量程精度只约束读数位数**：量程精度（分度值）决定示值显示到几位小数，用于 OCR 读数位数与人工录入校验；不参与 ±0.05% 判定。
6. **不合格记录同样留痕**：判定不通过的记录正常生成、保存、走复核流程，不因不合格而删除；当天不通过即该天平当天不可使用，处置在线下进行。
7. **较大误差提示**：读数偏差超过标称值 1% 时（自定义阈值），系统自动在备注写明偏差并提示"必要时报修"（预填、人可删改）；仅作提示/预填，不参与 ±0.05% 合格判定。

#### 3.1.6 校验记录状态流转
一条校验记录的状态机（记录物理保留、不删除）：

```
提交 → 待复核 ──复核通过──→ 已复核（生效）
        │  ▲
        │  └── 打回（重录新记录，本条标"已作废"）
        └── 已作废（录错/操作失误，检验员重录）
```

- 记录一经提交，**示值不可修改**；发现示值错误只能打回后重录新记录，旧记录标"已作废"；
- "已作废"记录**不记作废原因**，保留在库、默认不展示，可另行查询；
- "已复核"指"复核通过、记录生效"，**不等于校验合格**——一条"不通过"的记录同样会走到"已复核"。

#### 3.1.7 操作流程

**检验人员（日常校验）**
1. 拍摄：按操作规范录制整次校验（3 个砝码各称 3 次；双量程天平切换量程后再录第二个量程）；
2. 登录系统；
3. 新建校验，导入视频（当天录制、当天上传）；
4. 系统自动识别，显示拍摄人员、天平、量程与精度、9 次读数及读数时间；
5. 核对识别结果：与视频一致即通过；不一致就地修改（留痕），未识别到则补录；
6. 处理系统提示：量程 / 精度或读数位数不符时，回看视频确认后勾选"已确认"；
7. 勾选清洁、水平、内部校正；
8. 填写备注（较大误差时系统已自动填好）；
9. 确认并提交，记录进入"待复核"；
10. 如需更正已提交记录：重新校验并重新上传，原记录作废保留。

**检验人员（双量程天平，如 120 g / 40 g）**
1. 量程切到 120 g：称 100 g 砝码 3 次；
2. 切换量程到 40 g：称 20 g、2 g 砝码各 3 次；
3. 9 次示值逐次判定（100 g、20 g、2 g 各按自身限度）；任一示值超出限度，本次校验判不通过，并注明是哪个砝码不合格。

**复核确认人员**
1. 登录，打开"待复核确认"列表；
2. 逐条（或批量勾选）查看：读数表、称重值曲线、视频回放、前置条件与备注；
3. 选择处置方式：
   - 确认通过：记录生效，可导出 PDF；
   - 打回修改：检验人员重新校验（系统待办提示 + 线下通知）；
4. 确认或打回后记录锁定，任何人不可修改。

**管理员（日常维护）**
1. 登录；
2. 增加 / 删减检验人员、复核确认人员；
3. 重置密码。

#### 3.1.8 用例样例（格式示范）
**用例名**：检验人员导入并确认一次校验
- 参与者：检验人员
- 前置条件：已登录；已有当天录制的校验视频
- 主流程：
  1. 选择视频文件并导入；
  2. 系统识别人员二维码、天平二维码，按顺序预填 9 次示值与时间；
  3. 系统实时计算各砝码限度，逐示值判定并给出预判结果；
  4. 检验人员勾选清洁/水平/内部校正，核对示值与视频/照片一致（必要时人工改/补录，留痕），填写备注；
  5. 确认并提交，生成一条"待复核"记录。
- 异常流程：
  - 视频识别的人员二维码与登录人员不一致 → 不予记录并提示；
  - 识别不到示值 → 检验人员人工补录；
  - 示值核对后发现录错 → 打回后重录新记录，原记录标"已作废"。
- 后置条件：生成一条"待复核"的校验记录。

### 3.4 数据管理能力要求

**天平（主数据）**：天平编号、科室、天平唯一号(≤20位)、量程数量(单/双)、第一量程+精度、第二量程+精度、内部校正方式、校验频次、砝码盒唯一号(≤10位)、测量砝码 L1/L2/L3。其中量程精度用于约束读数位数。

> 砝码说明：砝码按**盒**管理——一盒砝码共用一个编号，盒内包含多种标称值的砝码；天平主数据记录的"砝码盒唯一号 + L1/L2/L3"表示从该盒取用的三个标称值。

**校验记录**：**主键 id**（数据库自增，作唯一键）、**记录号**（业务编号，自动生成 = 校验日期 + 天平编号 + 当日流水号，加唯一索引，仅作显示/查询用）、校验日期（=视频开始拍摄时间，分钟级）、天平、清洁/水平/内部校正是否通过、9 次示值（原屏数值、原屏单位、换算克值）+ 9 次测量时间（分钟级，查询页和导出 PDF 均显示）、外部校验是否通过、备注、校验人员、复核人员、**记录状态**（待复核/已打回/已复核/已作废）。

**识别值改动留痕**：当人工核对改动了识别值时，记录"原识别值 → 确认值"（仅改动项留痕，未改动项只存一个值）。

**唯一性说明**：业务上同一天平每天校验一次，但状态机允许同一天平、同一天存在多条物理记录（一条有效 + 若干已作废），故不能以"天平编号 + 日期"作唯一键，改为以自增 id 作主键（唯一键）；物理记录靠 id 区分、有效/作废靠"记录状态"区分。

### 3.5 故障处理要求

| 故障/异常 | 系统处理 |
|---|---|
| 视频识别的人员二维码与登录账号不一致 | 不予记录并提示 |
| 天平未登记或选错天平 | 提示，回看视频确认 |
| 量程或精度对不上 | 提示，可一键跳到视频对应时间，回看后勾选"已确认" |
| 读数位数不对 | 提示，可一键跳到视频对应时间，回看后勾选"已确认" |
| 识别不到示值 | 检验人员人工补录（兜底） |
| 示值核对后发现录错 | 打回后重录新记录，原记录标"已作废"（保留在库） |
| 视频画面不清晰/天平待机省电变暗 | OCR 仅作预填，最终以人工核对为准 |
| 通信中断/无法连接数据库 | 参照教材性能需求做法，系统应能监测并提示非正常情况 |
