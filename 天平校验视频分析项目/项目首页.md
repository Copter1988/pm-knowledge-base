# 天平校验视频分析系统 · 项目首页

> 课程项目（第 1 组）。将电子天平日常校验从「纸质手写」升级为「电子化记录」：手机录像 + 视觉识别（辅助录入）+ 人工核对，自动完成校验的记录、判定与归档。

## 项目关键信息速览

| 维度 | 内容 |
|---|---|
| 项目目标 | 电子化校验记录，留痕可回溯、自动判定、可查询导出 |
| 核心业务规则 | 3 砝码各称 3 次（9 次示值），示值须在标称值 ±0.05% 内 |
| 角色 | 管理员 1、检验人员 2（李一/李二）、复核确认人员 1（齐一） |
| 技术栈 | Java + MySQL + 简单前端，OCR 预留接口（不强制集成） |
| 部署 | 内网运行，并发 ≤ 5 人 |
