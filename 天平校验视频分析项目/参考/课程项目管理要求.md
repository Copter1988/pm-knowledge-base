# 课程项目管理要求（2025）

> 整理自 `项目管理要求2025.txt`。项目最终交付的要求与截止时间。

## 关键时间节点
- **12 月 19 日**：提交截止，上传百度网盘（分享地址 + 密码，**设永久有效**）。
- **12 月 15–24 日**：乙方协助甲方部署系统，使甲方能在自己环境运行。
- **12 月 26 日前**：客户甲方尽量完成项目评分。

## 项目提交清单（文件夹名：项目管理第*组）

### 一、软件项目
- **软件代码及配置环境**：相关软件及配置环境，打开即可方便配置运行。
- **软件文档**：需求说明、详细设计、代码、配置和使用说明等。

### 二、管理文档（按 PMBOK 知识领域分文件夹）
各知识领域下归类该领域内容，例如：
- 沟通管理 → 沟通计划 + 各次会议记录
- 进度管理 → 甘特图 + 跟踪
- 风险管理 → 风险管理 + 各次风险跟踪 Top5
- 配置管理 → 配置管理计划 + 各种变更单
- ……（课程涉及几大管理领域就建几个文件夹）

### 三、软件配置库
- 管理过程中的各种东西；若未配置软件，全部 copy 过来；
- 若为网上环境，写说明文件（访问地址、账号权限，开通最大权限）。

### 四、个人报告（文件名：`学号+姓名.doc`，每人一份）
> ⚠️ 个人报告太短或被查出 AI 生成 → **判定 0 分**。

内容：
1. 本人角色 + 具体工作；
2. 评价总结团队及项目经理工作，假想自己是项目经理会做哪些改进（项目经理则总结经验教训）；
3. 体会最深刻的 PMBOK 知识领域及原因；
4. 课程感受。

### 五、项目评分
- 项目经理自行制定评分标准，给除经理外的其他人员评分。
- 规则：项目得 X 分 → 项目经理得 X 分，其他人为含 X 的函数，**所有人员总分为 X×团队人数**；需给出评分依据。

### 六、项目汇报视频
- 从乙方向甲方角度陈述：项目功能、部署方法、使用方法、满足甲方需求的程度。
- 时长 ≤ 15 分钟，尽量控制文件大小。
