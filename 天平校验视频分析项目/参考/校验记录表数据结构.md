# 电子天平日常校验记录表 · 数据结构

> 整理自 `电子天平日常校验记录表 (1).xlsx`，共 3 个工作表。这是系统数据模型（校验记录、天平主数据）的**业务原型**来源。

## 工作表总览

| 工作表 | 用途 |
|---|---|
| 单日天平校验记录 | 单台天平某一天的校验明细（一次校验 9 次示值） |
| 每周天平校验统计记录 | 同一天平连续多日（一周）的校验记录汇总 |
| 天平清单 | 天平主数据 + 测量砝码配置 |

---

## 表 1 · 单日天平校验记录（单次校验的字段）

| 字段分组 | 字段 | 说明 |
|---|---|---|
| 基本信息 | 科室 | 如「化学室」 |
| | 天平唯一号 | 如 DZTP170911C |
| | Max(g) / d(mg) | 量程 / 精度 |
| | 内部校正方式 | 自动触发 / 手动触发 / NA（三选一） |
| | 校验日期 | 如 2026.06.29 |
| 前置条件 | 清洁 / 水平调节 | 是/否 |
| | 内部校正是否通过 | 是/否/NA |
| 砝码 1（L1） | 砝码唯一号 | 如 FM2512920 |
| | 标称质量值 | 如 200g |
| | 限度(1±0.05%) | 99.9000g~200.1000g |
| | 测量示值/时间 ×3 | (I1-1)~(I1-3) 及对应时间 |
| 砝码 2（L2） | 同上 | 如 50g，限度 19.9750g~20.0250g ⚠️ |
| 砝码 3（L3） | 同上 | 如 10g，限度 4.9950g~5.0050g |
| 结论 | 外部校正是否通过 | 是/否 |
| 签名 | 校验人员 / 复核确认人签名 | |

**备注（重要业务规则）**：
- 出现异常时应在备注栏准确记录，必要时及时报修。
- 拍摄扫描识别到设备二维码时，这些信息按每台天平具体确定，直接录入对应位置。
- 拍摄时录入：第一个数据输入日期、每个测量示值和时间（年月日时分）。
- 校验时除测量外的情况（仪器状态确认、异常记录「无/数值显示异常/无法稳定」），由系统提问 + 检验人员口述记录。
- 根据视觉输入自动判断，并根据进入系统的人员做校验人员电子登记，及后期复核确认人员进入系统的登记。

## 表 2 · 每周天平校验统计记录（多日汇总）

- 结构同表 1，但校验日期为**多列**（如 2026.06.29 ~ 07.03 逐日一列），每天重复整套「前置条件 + 3 砝码 9 示值」字段。
- 相当于把单日记录按天横向铺开，供一周统计。

## 表 3 · 天平清单（天平主数据）

| 字段 | 示例 | 说明 |
|---|---|---|
| 天平编号 | F001 / F002 | — |
| 科室 | 化学室 | — |
| 天平唯一号 | DZTP170911C / SJS2605002 | 设备自带，字母+数字，20 位以内 |
| 内部校正方式 | 自动触发 / 手动触发 / NA | 三选一 |
| 砝码唯一号 | FM2512920 / FM2512921 | 字母+数字，10 位以内，默认 FM2512921，可修改 |
| 天平量程数量 | 1 / 2 | 单量程或双量程 |
| 第一量程 / 精度 | 220g / 0.1mg | — |
| 第二量程 / 精度 | / 或 40g / 0.01mg | 双量程才有 |
| 测量示值 I1 / I2 / I3 | 200g/50g/10g 或 100g/20g/2g | 三个校验砝码的标称值 |
