## 2. 三视频验收步骤

### 2.1 校验记录闭环（video2，正例）

1. 用 `liyi`（JY001）登录，进 `/checker/record/import`。
2. 选天平 F001，上传 video2.mp4，点「导入并识别」。
3. 核对页应显示：校验员卡匹配、9 次示值自动预填（`AUTO_READING_OCR 9/9`）、无阻断。
4. 填前置条件（清洁/水平=是、内部校正=是），核对 9 次示值，点「提交复核」。
5. 应跳转到记录查询页，记录状态为「待复核」。
6. 用 `qiyi`（JY003）登录，进 `/reviewer/review/pending`，应看到这条待复核记录。
7. 点「确认」，状态变「已复核」。
8. 在 `/reviewer/records` 应能查到该记录，看曲线（L1/L2/L3 三张）、下载 PDF（中文正常、含测量时间与 g/mg 原屏值）。

### 2.2 身份阻断（video1，负例）

1. 用 `liyi`（JY001）登录，进 `/checker/record/import`。
2. 选天平 F002，上传 video1.mp4，导入。
3. 核对页应显示「存在阻断问题」+ `blockingMessage`「视频检验员身份和登录身份不匹配，不予校验」，**不显示 9 次示值表、无提交按钮**。
4. 确认没有生成任何 `calibration_record` / `reading` 记录。

### 2.3 g/mg 混合显示（video3，正例）

1. 用 `liyi`（JY001）登录，导入 video3.mp4（F002 + JY001）。
2. 核对页应保留前 3 次 `g`、后 6 次 `mg` 的原屏单位，并完成克值换算。
3. 提交 → 复核确认 → 查询/PDF 应能正确显示原屏单位与换算克值。

### 2.4 作废与账号/主数据（补验）

- 作废：在 `/checker/record/list` 对一条待复核记录点「作废」，状态变「已作废」；查询页勾选「含作废」能调出。
- 账号：`admin` 登录 `/admin/users` 新增/停用账号、重置密码。
- 主数据：`admin` 登录 `/admin/masterdata` 新增双量程天平、编辑、删除；维护砝码盒。

## 3. 验收对照

| 编号 | 条目 | 怎么验证 |
|---|---|---|
| AC-01 | 三类角色登录与权限隔离 | liyi/qiyi/admin 登录后只进各自菜单 |
| AC-02 | 导入 3 视频（2 正确 1 错误），先核身份再识别示值 | video2/video3 匹配自动预填；video1 提前阻断 |
| AC-03 | 人员/天平不一致提示 | video1 显示 PERSON/CHECKER 不匹配 |
| AC-05 | 复核确认/打回，确认后锁定 | 待复核→已复核，确认后不可再改 |
| AC-06 | 查询/曲线/PDF | 按天平+日期查、三组曲线、记录表式 PDF |
| AC-07 | 单视频 ≤2 分钟、并发 ≤5、≤3 步 | 核对页 `elapsedMillis` ≤120000；步骤=导入→核对→提交 |
