# 应用功能完善性检查流程

> 用途：系统上线/验收前，逐项检查功能是否完整、可用。
> 使用：按顺序逐项勾选，任何一项「预期结果」不符，即为缺陷。

---

## 0. 环境与启动

- [ ] ffmpeg 就绪（`D:/ffmpeg/bin/ffmpeg.exe`，或 `application.yml` 里配的路径存在）
- [ ] 本地 OCR 就绪（`.ocr-venv` 已装，`test_local_ocr_worker.py` 5 tests OK）
- [ ] MySQL 运行中（3306 端口，`tpjy` 库、`reading` 表含 `display_value/display_unit` 列）
- [ ] 启动应用无报错，`http://localhost:8080/login` 能打开

---

## 1. 登录与角色权限

| 检查项 | 操作 | 预期结果 |
|---|---|---|
| 登录跳转 | 用 `liyi`/`qiyi`/`admin` 分别登录 | CHECKER→我的校验记录，REVIEWER→待复核确认，ADMIN→账号维护 |
| 错误密码 | 输入错误密码 | 提示「账号或密码错误」，不进入系统 |
| 停用账号 | 停用 `lier` 后用它登录 | 无法登录 |
| 越权访问 | CHECKER 访问 `/admin/**` | 被拦截，跳回首页 |
| 顶栏菜单 | 各角色看顶栏 | 只显示本角色的菜单，无缺失、无越权项 |

## 2. 检验人员（CHECKER）

| 检查项 | 操作 | 预期结果 |
|---|---|---|
| 导入视频 | 顶栏「新建校验」→ 选天平 F001 → 上传 JY001 视频 | 进入核对页，耗时 ≤2 分钟 |
| 识别身份 | 看核对页身份表 | 人员/天平/校验员卡识别正确 |
| 身份阻断 | 用 `liyi`(JY001) 上传 JY002 视频 | 显示「身份不匹配」阻断，**无提交按钮、不落库** |
| 前置条件 | 填清洁/水平/内部校正 | 落库到对应字段 |
| 9 次示值改值 | 改某次示值后提交 | 该次留痕（read_trace + 审计） |
| 提交复核 | 点「提交复核」 | 记录状态变「待复核」，跳查询页 |
| 我的记录 | 顶栏「我的校验记录」 | 列出自己的草稿/待复核/已打回记录 |
| 作废 | 对一条记录点「作废」 | 状态变「已作废」，查询页勾「含作废」可调出 |
| 记录查询 | 顶栏「记录查询」 | 按天平+日期查询，默认只显「已复核」 |

## 3. 复核人员（REVIEWER）

| 检查项 | 操作 | 预期结果 |
|---|---|---|
| 待复核列表 | 顶栏「待复核确认」 | 列出所有「待复核」记录 |
| 单条确认 | 点「确认」 | 状态变「已复核」，写复核人/时间，审计留痕 |
| 打回 | 点「打回」 | 状态变「已打回」（不是已作废） |
| 批量确认 | 勾选多条 →「批量确认」 | 选中项全部变「已复核」，记 BATCH_CONFIRM |
| 查询导出 | 顶栏「查询与导出」 | 查「已复核」记录 |
| 曲线 | 查询页点「曲线」 | L1/L2/L3 三组趋势图正常显示 |
| PDF | 查询页点「下载 PDF」 | 生成 PDF，含测量时间、原屏 g/mg 与换算克值 |
