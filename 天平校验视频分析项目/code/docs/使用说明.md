## 二、检验人员（CHECKER）操作

检验人员的完整流程：**导入视频 → 核对身份与示值 → 提交复核 → 管理自己的记录**。

### 1. 导入视频

- 地址：`/checker/record/import`（见文末「入口提示」）
- 选择天平（如 F001），选择校验视频文件，视频号可留空，点「导入并识别」。
- 系统会落盘视频，用 ffmpeg 抽帧 + 本地 OCR 识别身份卡、天平铭牌与 9 次稳定示值（约 30~90 秒，勿重复点击）。

### 2. 核对与提交

识别完成后进入核对页，逐项核对：

- **身份核对**：人员、天平、视频内校验员卡号与登录账号绑定卡号是否一致。
  - ⚠️ 若显示「存在阻断问题」+「视频检验员身份和登录身份不匹配」，表示视频里的校验员卡和当前账号不一致，**不能建记录**，请换对视频或换对应账号。
- **前置条件**：清洁是否符合要求（是/否）、水平调节是否到位（是/否）、内部校正（是/否/NA，NA 不算不通过）。
- **9 次示值**：系统自动预填识别到的稳定示值，可**人工修改**（支持 g/mg，如 `200.0008g` 或 `20000.8mg`）。改过的值会留下「原值 → 确认值」留痕。
- **备注**：可留空，系统会自动采用判定预填的备注（如较大误差提示）。
- 点「提交复核」，记录以「待复核」状态落库，提交后示值锁定。

### 3. 我的记录与作废

- 地址：`/checker/record/list`
- 列出当前检验人员提交的「草稿/待复核/已打回」记录。
- 对录错的记录可点「作废」，状态变为「已作废」（保留在库，查询页勾选「含作废」可调出）。

## 三、复核确认人员（REVIEWER）操作

复核流程：**待复核列表 → 确认或打回 → 查询/曲线/PDF**。

### 1. 待复核确认

- 地址：`/reviewer/review/pending`（登录后顶栏「待复核确认」会自动跳转到这里）
- 显示所有「待复核」记录。
- **确认**：状态变为「已复核」，记录锁定、不可再改，写复核人与时间。
- **打回**：状态变为「已打回」（可填原因）。
- **批量确认**：勾选多条后点「批量确认选中项」。

### 2. 查询 / 曲线 / 导出

- `/reviewer/records`：按天平 + 日期段查询，默认只显示「已复核」，可勾选「含作废」。
- `/reviewer/curve`：查看某条记录的 L1/L2/L3 三组称重值趋势图。
- `/reviewer/export/pdf`：仅「已复核」记录可导出记录表式 PDF（含每次测量时间、原屏 g/mg 值与换算克值）。

## 四、管理员（ADMIN）操作

### 1. 账号维护

- 地址：`/admin/users`
- 新增账号（账号/姓名/角色/校验员卡号，默认密码 123456）、停用/启用、重置密码。

### 2. 主数据维护

- 地址：`/admin/masterdata`
- **天平**：新增（含单量程/双量程、砝码 L1/L2/L3 标称值）、编辑、删除。
- **砝码盒**：新增、删除（一盒一号）。
- **记录模板**：维护字段的显示名、显隐、排序。

## 五、关键业务规则（使用者须知）

1. **身份先核**：视频内的校验员实体卡（JYxxx）必须与登录账号绑定卡一致，否则系统在识别示值前就阻断，不建记录。
2. **归组规则**：9 次示值按顺序归组——第 1~3 次 = L1，4~6 次 = L2，7~9 次 = L3（与天平量程无关）。
3. **判定限度**：标称值 × (1 ± 0.05%)，实时计算；示值超出限度即判该次不合格。
4. **内部校正 NA**：不算不通过。
5. **已作废记录**：保留在库、默认不展示、不记作废原因，可勾选「含作废」查询。
