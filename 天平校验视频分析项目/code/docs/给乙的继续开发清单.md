## 1. 先验证环境

1. 解压后进入 `天平校验视频分析项目/code`。
2. 设置本机 MySQL 凭据：

   ```powershell
   $env:TPJY_DB_USER="root"
   $env:TPJY_DB_PASSWORD="你的密码"
   ```

3. 安装文字卡 OCR（首次需要联网，之后本地运行）：

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\scripts\setup-local-ocr.ps1
   ```

4. 构建并运行测试：

   ```powershell
   mvn -s mvn-settings.xml clean test
   .\.ocr-venv\Scripts\python.exe .\scripts\test_local_ocr_worker.py
   ```

   当前基线应为 Java **46 tests, 0 failures**，本地 OCR **4 tests, OK**。

5. 启动：

   ```powershell
   mvn -s mvn-settings.xml spring-boot:run
   ```

   登录页：`http://localhost:8080/login`。

## 2. 甲已经提供的接口

- `VideoStorageService.store(...)`：视频安全落盘。
- `RecognitionService.recognize(...)`：二维码 + 天平卡/校验员卡 OCR + 账号卡号匹配 + 铭牌精度比对 + 9 次稳定示值自动 OCR 预填。
- `JudgeService.judgeRecord(...)`：实时限度、逐示值判定、一票否决、备注预填。
- `QueryService.page/detail/curve(...)`：记录查询、详情、趋势数据。
- `CurveRenderer.render(...)`：L1/L2/L3 三分组趋势图。
- `PdfExportService.export(...)`：仅已复核记录可导出记录表式 PDF。
- `AuditService`：五类审计 + 登录。
- `VideoRetentionService`：7 天视频清理与删除留痕。

接口细节见同目录 `接口说明.md`。
