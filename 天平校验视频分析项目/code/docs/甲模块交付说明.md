## 2. 与乙模块的边界

甲模块负责识别结果、判定结果、查询/曲线/PDF 与审计能力，不代替乙的：

- 1.3.3 记录落库、人工核对改值、提交、作废；
- 1.3.4 复核确认/打回与锁定；
- 1.3.1 账号维护；
- 1.3.7 天平/砝码/模板维护。

乙在记录管理模块应：

1. 调 `VideoStorageService.store(...)` 保存上传视频；
2. 调 `RecognitionService.recognize(...)` 获取 `RecognitionResult`；
3. 创建记录前检查 `RecognitionResult.canCreateRecord()`；人员不一致必须阻断；
4. 调 `JudgeService.judgeRecord(...)` 得到逐项判定、总结论和备注预填；
5. 保存 `video`、`calibration_record`、`reading`、`read_trace`；
6. 改值时调 `AuditService.logReadChange(...)`，作废/复核/批量确认/删视频同理。

## 5. 启动提醒

1. 设置环境变量 `TPJY_DB_USER`、`TPJY_DB_PASSWORD`（或修改 `application.yml` 的默认值）；
2. 确认 `app.ffmpeg-path` 指向 `E:/ffmpeg/bin/ffmpeg.exe`；
3. 运行 `mvn -s mvn-settings.xml spring-boot:run`；
4. 打开 `http://localhost:8080/login`。

数据库每日备份可使用 `scripts/backup-tpjy.ps1`。先在当前用户环境中设置
`TPJY_DB_USER`、`TPJY_DB_PASSWORD`，再通过 Windows 任务计划程序每天执行一次；
脚本默认保留 30 天备份，不把密码写入仓库。
