## 7. 关键约定（数据对不上的坑）

- 限度实时算 `标称值 × (1±0.05%)`，绝不引用 xlsx 限度栏
- 归组只看 `seq`：1~3→L1、4~6→L2、7~9→L3（双量程也一样）
- `reading` 三列：`reading_value`（换算 g，判定用）+ `display_value`（原屏）+ `display_unit`
- 记录号 `JY + yyyyMMdd + "-" + 3位当日流水`（用现成 `TpjyUtils.recordNo`）
- 校验员卡不匹配/未配置 → `canCreateRecord()` 返回 false，必须阻断，`readings` 为空是预期
- 内部校正 `NA` 不算不通过；已作废记录不记原因、默认不展示
- 打回状态用 `Constants.STATUS_REJECTED`（已打回），不是「已作废」
