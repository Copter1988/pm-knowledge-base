## 0. 一次性环境准备（5 分钟）

### 0.1 设 Maven 配置（必须，否则依赖拉不下来）

本机全局 `.m2/settings.xml` 用的是 `maven.aliyun.com`，**这个域名在本机 DNS 解析失败**，
而 `repo.maven.apache.org` 也不通，只有 `repo1.maven.org` 能用。工程里已放好 `mvn-settings.xml`。

- **IDEA**：`File → Settings → Build, Execution, Deployment → Build Tools → Maven` →
  `User settings file` 勾选 Override，选代码目录下的 `mvn-settings.xml`
- 命令行方式见 README

### 0.2 确认 JDK

```powershell
java -version     # 期望 17.0.12（或 8/11 均可）
echo $env:JAVA_HOME   # 期望 E:\java
```

### 0.3 安装 ffmpeg（抽帧用）

1. 下载 `ffmpeg-release-essentials.zip`（gyan.dev），解压到 `E:\ffmpeg`
2. 确认 `E:\ffmpeg\bin\ffmpeg.exe` 存在
3. 在 `src/main/resources/application.yml` 里改：
   ```yaml
   app:
     ffmpeg-path: E:/ffmpeg/bin/ffmpeg.exe
   ```
   **不需要配环境变量**。

若不想装 ffmpeg：把 `app.frame-extractor` 改成 `javacv`，并按 `docs/接口说明.md` 的「JavaCV 备选」加依赖 + 实现类。

### 0.4 放中文字体（导出 PDF 用）

```powershell
copy C:\Windows\Fonts\simhei.ttf .\src\main\resources\fonts\simhei.ttf
```

不放也能生成 PDF，但中文会变成方框（`PdfExportService` 会打印一行警告）。
注意 `simsun.ttc` 是字体集合，Flying Saucer 不支持，别用。

### 0.5 安装文字身份卡 OCR（可选）

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\setup-local-ocr.ps1
```

RapidOCR 和模型都在本机运行，不上传视频。未安装时，系统仍可用二维码或手动选择天平。

## 1. 三条跑通路径（从易到难）

### 路径 A：只跑测试（不需要数据库、不需要 ffmpeg）

```powershell
$env:JAVA_HOME="E:\java"
& "E:\IDEA\IDEA2026\IntelliJ IDEA 2026.1.2\plugins\maven\lib\maven3\bin\mvn.cmd" -s mvn-settings.xml test
```

期望：`Tests run: 42, Failures: 0, Errors: 0` + `BUILD SUCCESS`。
同时会在 `target/` 生成 `sample-curve.png` 与 `sample-record.pdf`，**先打开这两个看看效果对不对**。

### 路径 B：命令行识别你的真实视频（需要 ffmpeg）

1. 把视频放到代码目录的 `videos/`（如 `v1_ok.mp4`、`v2_ok.mp4`、`v3_bad.mp4`）
2. IDEA 里右键 `com.tpjy.cli.AnalyzeCli` → Run，Program arguments：

```
--video=videos/v1_ok.mp4 --person=李一 --balance=F001 --weights=200,50,10 --precision=0.1mg --known-balances=F001,F002 --out=out
```

3. 看 `out/` 目录与 `out/judge.txt`

> 视频里没有二维码卡片时，`--person` / `--balance` 会作为「人工指定」使用，
> 此时会输出 `QR_MISSING` 的 INFO 提示（不算错），示值走人工补录。

### 路径 C：先造一个演示视频再跑（没有合适素材时）

1. 右键 `com.tpjy.cli.MakeDemoVideoCli` → Run，参数：
   ```
   --out=videos --name=demo --person=李一 --balance=F001 --seconds=12
   ```
2. 再用路径 B 跑 `videos/demo.mp4`（带上 `--values=...` 九个示值，用来验证判定链）

## 2. AnalyzeCli 参数全表

| 参数 | 说明 | 示例 |
|---|---|---|
| `--video=` | **必需**，校验视频 | `videos/v1_ok.mp4` |
| `--person=` | 当前检验人员姓名（用于「拍摄人员与登录账号一致」查对；视频无人员卡时按此记录） | `李一` |
| `--balance=` | 选定的天平编号 | `F001` |
| `--weights=` | L1/L2/L3 砝码标称值（g），判定与限度计算必需 | `200,50,10` |
| `--precision=` | 第一量程精度，换算「应显示位数」 | `0.1mg` |
| `--precision2=` | 双量程第二量程精度（L2/L3 使用） | `0.01mg` |
| `--range1-capacity=` | 第一量程容量，用于超量程告警 | `120g` |
| `--range2-capacity=` | 第二量程容量，用于选择细精度档 | `41g` |
| `--digits=` | 直接指定应显示位数（优先于 precision） | `4` |
| `--known-balances=` | 已登记天平清单，用于「天平未登记」提示 | `F001,F002` |
| `--values=` | 人工补录/模拟 9 个示值，支持 g/mg（Noop OCR 下用它验证判定、趋势图、PDF） | `200.0006g,20000.2mg,...` |
| `--status=` | CLI 生成 PDF 时的记录状态；只有 `已复核` 可导出 | `已复核` |
| `--clean=` `--level=` | 前置条件：清洁 / 水平（1 是 / 0 否） | `--clean=1` |
| `--calib=` | 内部校正：`是` / `否` / `NA`（NA 不算不通过） | `--calib=是` |
| `--check-date=` | 校验日期（默认取视频文件时间） | `"2026-06-29 10:13"` |
| `--seq=` `--video-seq=` | 记录号 / 视频号流水 | `--seq=11 --video-seq=43` |
| `--interval=` | 抽帧间隔秒（默认 1） | `--interval=2` |
| `--ffmpeg=` | ffmpeg.exe 路径（默认取 PATH） | `E:/ffmpeg/bin/ffmpeg.exe` |
| `--out=` | 输出目录 | `out` |
| `--no-pdf` | 不导出 PDF | — |
| `--font=` | 中文字体 ttf 路径 | `E:/ffmpeg/../fonts/simhei.ttf` |

## 3. 常见报错 → 原因 → 处置

| 报错 / 现象 | 原因 | 处置 |
|---|---|---|
| `非解析的 POM / Non-parseable POM` | pom.xml 注释里写了 `--`（XML 注释不允许） | 已经修好；以后别在注释里写 `--` |
| `Error reading old mojo status ... inputFiles.lst` | 增量编译状态文件与当前编码不一致（中文路径 + 改过 `file.encoding`） | 跑一次 `mvn clean test`（或直接删掉 `target` 目录） |
| 依赖下载失败：`UnknownHost maven.aliyun.com` | 全局 settings.xml 指向的镜像在本机解析不了 | 用工程自带的 `mvn-settings.xml`（见 0.1） |
| 依赖下载失败：`UnknownHost repo.maven.apache.org` | 该主机名在本机不通 | `mvn-settings.xml` 已改成 `repo1.maven.org` |
| `无法启动 ffmpeg（路径：ffmpeg）` | ffmpeg 未安装或不在 PATH | 装 ffmpeg 并配 `app.ffmpeg-path` 为绝对路径 |
| `ffmpeg 抽帧失败（exit=1）` | 视频损坏 / 编码不支持 / 路径含特殊字符 | 换一个 mp4 试；用 `--ffmpeg` 指定绝对路径；避开中文路径 |
| `抽帧结果为空` | 视频时长过短或抽帧间隔过大 | 用 `--interval=1`；或换更长的视频 |
| `抽帧超时（超过 120 秒）` | 视频过大 | 调小视频分辨率/时长，或调大 `app.recognize-timeout-seconds` |
| 识别不到二维码（`QR_MISSING`） | ① 视频里根本没有二维码卡片；② 卡片太小/太糊/反光 | 用 `--person` `--balance` 人工指定；或提高拍摄清晰度、让卡片占画面更大 |
| 印刷文字卡未识别 | `.ocr-venv` 未安装或 RapidOCR 初始化失败 | 执行 `scripts/setup-local-ocr.ps1`；查看控制台“文字卡 OCR 失败”信息 |
| 人员卡识别成别人（`PERSON_MISMATCH`） | 视频里拍的是另一个人的人员卡 | 这是**正确行为**（SRS 要求不予记录并提示）；换对视频或核对卡片 |
| 天平提示未登记（`BALANCE_NOT_FOUND`） | 天平编号不在 `--known-balances` 里 | 加上该编号，或先去主数据里登记这台天平 |
| 提示「位数不符」 | 示值小数位数与量程精度不匹配 | 这是**正确行为**（界面原型里就有这条）；核对量程/精度设置 |
| `9 次示值只有部分有值` | Noop OCR 不识别数字（设计如此） | 用 `--values=` 传入，或在页面上人工补录 |
| PDF 导出一片方框 / 空白 | 没放中文字体 | 见 0.4 放 `simhei.ttf`；或 `--font=<绝对路径>` |
| `PDF 导出失败：...判定...` | 还没做判定就想导出 | 正常流程：识别 → 判定 → 导出 |
| 启动 Web 报 `Communications link failure` | MySQL 没启动 / 密码不对 | 启动 MySQL；改 `application.yml` 的账号密码 |
| 启动 Web 报 `Unknown database 'tpjy'` | 库不存在 | 连接串已带 `createDatabaseIfNotExist=true`，确认账号有建库权限 |
| 时区/时间差 8 小时 | 连接串时区参数 | 已带 `serverTimezone=Asia/Shanghai` |
| 表里没有 `record_template` | 以前跑过旧版建表脚本 | `spring.sql.init.mode=always` 会自动补；或手动执行 `schema.sql` |

## 4. 结果自检清单（告诉你"跑对了没有"）

跑完 `AnalyzeCli` 后逐条对：

- [ ] `out/recognize.json` 里 `frameCount` > 0，`elapsedMillis` ≤ 120000（对应 NFR-001）
- [ ] `recognize.json` 里 `personFromQr` / `balanceFromQr` 与视频里的卡片一致
- [ ] `alerts` 里的提示类型符合预期（人员不一致 / 天平未登记 / 位数不符 / 未识别到）
- [ ] `out/judge.json` 里 9 条 `details`，每条 `lower`/`upper` 是按标称值**实时算**出来的
- [ ] 上限校验：200 g → 200.1000；50 g → 50.0250（**不是**记录表里写错的 20.0250）
- [ ] L3 的 10.0060 判为「不合格」，且 `failReasons` 里能看到「L3 砝码对应的示值不合格」
- [ ] `out/curve.png` 能打开，包含 L1/L2/L3 三个面板；超限点位于 ±0.05% 虚线外且为红色
- [ ] `out/record.pdf` 能打开，中文正常显示（不是方框）
- [ ] `record.pdf` 里能看到每次示值的测量时间、天平实际 g/mg 显示和换算克值
- [ ] `out/audit.log` 里有 LOGIN / RECOGNIZE 记录
