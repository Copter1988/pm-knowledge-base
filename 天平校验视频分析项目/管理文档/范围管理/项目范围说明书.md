# 项目范围说明书（Project Scope Statement）

> 项目名称：天平校验视频分析系统　|　组别：第 1 组　|　编制日期：2026-09-30
> 依据：[[../需求规格说明书-SRS]]（SRS 已定稿）

## 1. 项目目标

将电子天平日常校验从「纸质手写」升级为「电子化记录」，通过「手机录像 + 视觉识别（辅助录入）+ 人工核对」自动完成校验的记录、判定与归档。三大核心价值：

1. **留痕可回溯**：校验过程录像留证，识别值与人工确认值的改动均留痕；
2. **自动判定**：按 ±0.05% 规则自动判定每次校验是否通过；
3. **记录电子化**：可查询、可导出 PDF、可生成称重值曲线图。

## 2. 产品范围描述

系统是一个**内网运行**的 Web 应用，面向三类角色（管理员、检验人员、复核确认人员），核心业务闭环：

```
拍摄校验视频 → 导入系统 → 视觉识别（二维码 + OCR 预填 9 次示值）
→ 人工核对/补录（留痕）→ 自动判定（±0.05% + 前置条件一票否决）
→ 提交 → 复核确认/打回 → 查询 / 曲线图 / 导出 PDF
```

## 3. 项目范围

### 3.1 项目内（in scope）
- 校验视频导入与视觉识别（人员/天平二维码识别 + 示值 OCR 预填）；
- 人员 / 天平二维码识别与匹配（与登录账号、已登记天平核对）；
- 校验记录管理（录入、核对、提交、复核、打回、作废、查询、导出）；
- 校验自动判定（限度实时计算、逐示值判定、前置条件一票否决、较大误差标记）；
- 三类角色（检验人员 / 复核确认人员 / 管理员）及权限；
- 天平与砝码信息维护、校验模板维护；
- 留痕与审计日志、视频 7 天保留、数据库备份。

### 3.2 项目外（out of scope）
- 天平的内部校正 / 自动校准本身（系统只管外部校验记录）；
- LIMS 系统的开发（只做数据对接 / 预留）；
- 视频识别 AI 模型的训练（OCR 采用本地开源模型 / 预留接口，不做自研训练）；
- 天平可用状态管理（只记录"通过/不通过"，不合格后的报修停用在线下进行）。

## 5. 验收标准

1. 三类角色均可登录并按各自权限操作（管理员增删账号/重置密码）；
2. 能导入 3 个校验视频（2 正确 1 错误）；正确视频可自动识别人员、天平、9 次示值与时间；
3. 视频中人员与登录账号不一致、天平未登记等情况能被系统提示；
4. 校验判定与业务规则一致：限度 = 标称值 ±0.05% 实时计算；9 次示值逐次判定；清洁/水平/内部校正任一项不通过即一票否决；
5. 复核确认 / 打回流程正确，确认后数据锁定不可改；
6. 可按天平编号 + 日期段查询，生成称重值曲线图，导出复核通过的 PDF；
7. 非功能要求达标：单视频识别 ≤ 2 分钟、并发 ≤ 5 人、"导入→核对→提交" ≤ 3 步。

## 6. 约束与假设

- **约束**：技术栈尽量简单（Java + MySQL + 简单前端，OCR 预留接口）；内网运行；人员为项目组（第 1 组）。
- **假设**：手机拍摄画面清晰、二维码可识读、示值可见；示值需在**稳定后**读取（1~2 秒不跳动）；OCR 仅作预填，最终以人工核对为准。

## 7. 范围排除项说明

本项目不做 AI 模型自研训练、不做 LIMS 开发、不做天平内部校正与不合格后的线下处置流程——这些均已明确排除，避免范围蔓延（scope creep）。
