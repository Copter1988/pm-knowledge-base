# 项目配置环境基线

> 项目名称：天平校验视频分析系统　|　组别：第 1 组　|　版本：V1.0　|　日期：2026-11-02
> 适用基线：`feature/yi-modules` 合并后的代码基线
> 关联：[[配置管理计划（含配置项清单）]]、[[变更单与状态报告]]

## 1. 目的与适用范围

本文件定义开发、自动化测试和验收演示所需的最小环境，确保同一份源代码能在乙、评审机和甲方演示环境中以一致方式构建、启动和验证。

本基线不保存真实密码、真实视频或本机专属 OCR 虚拟环境。上述内容通过环境变量、本地安装脚本和受控交付介质管理。

## 3. 环境变量与路径

### 3.1 必需变量

```powershell
$env:TPJY_DB_USER = "root"
$env:TPJY_DB_PASSWORD = "本机数据库密码"
```

不得把真实密码写入 `application.yml`、提交说明、文档或截图。

### 3.2 应用配置项

| 配置键 | 默认值 | 验收建议 |
|---|---|---|
| `server.port` | `8080` | 冲突时通过启动参数覆盖 |
| `spring.datasource.url` | `jdbc:mysql://localhost:3306/tpjy...` | 验收使用实际 MySQL 8 地址 |
| `app.video-dir` | `./upload/video` | 保持可写，预留至少 5GB |
| `app.frame-dir` | `./upload/frame` | 每段视频会产生 270～400 张帧图 |
| `app.ffmpeg-path` | `${FFMPEG_PATH:ffmpeg}` | 未设置 `FFMPEG_PATH` 时自动搜索 E:/C:/D: 常见位置，也可显式指定绝对路径 |
| `app.card-ocr-enabled` | `true` | 验收必须启用 |
| `app.ocr-python-path` | `./.ocr-venv/Scripts/python.exe` | 相对 `code/` 目录解析 |
| `app.ocr-worker-path` | `./scripts/local_ocr_worker.py` | 必须可读 |
| `app.card-ocr-timeout-seconds` | `150` | 高负载机器可临时调高，但需重测 NFR |
| `app.numeric-ocr-max-frames` | `320` | 超长视频自动等间隔采样 |
| `app.pdf-font-path` | `/fonts/simhei.ttf` | PDF 中文必须验证 |

### 3.3 环境矩阵

| 项目 | DEV 开发 | TEST 自动化 | UAT/演示 |
|---|---|---|---|
| 数据库 | MySQL 8 本地 `tpjy` | H2 内存库 | MySQL 8 独立演示库 |
| OCR | 启用 | Java 测试关闭；Python 测试单独运行 | 启用 |
| ffmpeg | 必需 | 真实视频测试需要 | 必需 |
| Spring 模板缓存 | 关闭 | 关闭 | 建议开启 |
| SQL 日志 | 可开启 | 按测试需要 | 关闭或降级 |
| 测试数据 | 可重置 | 每次测试生成 | 使用受控种子/脱敏数据 |
| 默认密码 | 仅开发 | 测试固定 | 交付前修改 |

## 4. 首次搭建步骤

### 4.1 获取代码

```powershell
git clone git@github.com:Copter1988/pm-knowledge-base.git
cd pm-knowledge-base
git checkout feature/yi-modules
cd .\天平校验视频分析项目\code
```

### 4.2 构建与测试

```powershell
mvn -s mvn-settings.xml clean package
```

验收基线：

```text
Java tests: 78, failures 0
Spring Boot package: BUILD SUCCESS
```

### 4.3 安装本地 OCR

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\setup-local-ocr.ps1
.\.ocr-venv\Scripts\python.exe .\scripts\test_local_ocr_worker.py
```

验收基线：`Ran 5 tests ... OK`。

### 4.4 启动 MySQL

确认：

- 端口 `3306` 可连接；
- 账号有 `tpjy` 建库/建表权限；
- `application.yml` 的时区为 `Asia/Shanghai`；
- 旧库启动后 `sys_user.card_code`、`reading.display_value/display_unit/measure_time` 等列存在。

### 4.5 IDEA 启动

1. `File → Open` 打开 `code` 目录；
2. Project SDK 选择 JDK 17；
3. Maven User settings 选择 `code/mvn-settings.xml`；
4. 在 `TpjyApplication` Run Configuration 的 Environment variables 中加入：

```text
TPJY_DB_USER=root;TPJY_DB_PASSWORD=实际密码
```

5. 运行 `com.tpjy.TpjyApplication`；
6. 打开 `http://localhost:8080/login`。

> 不要把数据库密码写进 IDEA 的共享 `.idea` 文件并提交 Git。

### 4.6 一键环境自检

```powershell
$env:TPJY_DB_USER = "root"
$env:TPJY_DB_PASSWORD = "本机数据库密码"
powershell -ExecutionPolicy Bypass -File .\scripts\check-environment.ps1 `
  -MavenCommand "C:\path\to\mvn.cmd" `
  -FfmpegPath "E:\ffmpeg\bin\ffmpeg.exe"
```

脚本只检查环境并输出 PASS/FAIL/WARN，不输出数据库密码。任何 FAIL 必须先处理再进入 UAT。

## 6. 备份、发布与回滚

### 6.1 发布前

1. 功能冻结，运行 78+5 项测试；
2. 备份数据库；
3. 保存上一版本 JAR 和配置；
4. 导出当前 `git rev-parse HEAD`；
5. 记录环境核对表。

### 6.2 发布

```powershell
mvn -s mvn-settings.xml clean package
java -jar target\tpjy-1.0.0.jar
```

### 6.3 回滚

1. 停止应用；
2. 恢复上一版本数据库备份；
3. 回退 JAR/配置；
4. 启动并执行登录、查询、上传、PDF Smoke Test；
5. 在变更单中记录回滚原因和证据。

## 7. 环境变更控制

以下变更必须登记配置变更：

- JDK、Spring Boot、MySQL、ffmpeg、RapidOCR 主/次版本升级；
- 数据库结构、端口、时区、字符集、PDF 字体变化；
- OCR 模型/依赖或 ffmpeg 路径策略变化；
- 生产环境账号、权限和密钥管理方式变化。

环境变更后必须重跑：

```powershell
mvn -s mvn-settings.xml clean package
.\.ocr-venv\Scripts\python.exe .\scripts\test_local_ocr_worker.py
```

并抽查 video1 身份阻断、video2 正常 9/9、PDF 中文与视频播放。
