# 软件项目成本计划（成本估算与预算）

> 项目名称：天平校验视频分析系统　|　组别：第 1 组　|　编制日期：2026-10-01
> 依据：[[../../需求规格说明书-SRS]]、[[../范围管理/WBS工作分解结构]]、[[../范围管理/WBS字典]]
> 对应教材：[[第6章 软件项目成本计划]]

## 0. 编制说明

- **目的**：估算本项目规模、工作量与成本，并形成**成本基线**，作为后续成本跟踪与监控的依据。
- **路径**：规模估算 → 工作量估算 → 成本估算 → 成本预算 → 成本基线（教材 §6.1.3）。
- **主方法**：**自下而上估算法**（基于 [[../范围管理/WBS工作分解结构]] 的 25 个工作包逐项估时）。
- **交叉验证**：**故事点估算**（敏捷法，教材 §6.3），两法结果应接近。
- **成本口径**：软件成本以**人力消耗为主**，仅含人力成本 + 非人力成本，不含数据迁移与维护成本（教材 §6.1.2）。SDC = DHC + DNC + IHC + INC。
- **说明**：本项目为**课程实训项目**，以下费率、工时为教学口径的假定值，可按实际情况替换。

## 3. 成本估算

### 3.1 估算方法与费率假设

- **直接人力成本**（教材式 6-1）：DHC = Σ 工作量 × 费率；本项目人员同类，取**综合费率 = 100 元/人时**（= 800 元/人天）。
- **规模调整**：课程项目需求已定稿、变更有限，不额外乘规模调整因子。

### 3.2 成本构成（SDC = DHC + DNC + IHC + INC）

| 成本项 | 计算 | 金额(元) |
|---|---|---|
| 直接人力成本 DHC | 282 人时 × 100 元/人时 | 28,200 |
| 直接非人力成本 DNC | 打印装订、资料、网盘等 | 300 |
| 间接人力成本 IHC | DHC × 10%（管理/支持分摊） | 2,820 |
| 间接非人力成本 INC | DHC × 5%（房租水电/办公分摊） | 1,410 |
| **总估算成本 SDC** | | **32,730** |

> 总成本 ≈ **3.27 万元**（人均约 1.64 万元）。

### 3.3 三点估算（区间，教材 §6.2.6）

| | 最乐观 CO | 最可能 CM | 最悲观 CP |
|---|---|---|---|
| 工作量(人时) | 245 | 282 | 345 |
| 总成本(万元) | 2.90 | 3.27 | 4.10 |

- 贝塔分布：CE = (CO + 4CM + CP) / 6 = (2.90 + 4×3.27 + 4.10) / 6 ≈ **3.37 万元**
- 三角分布：CE = (CO + CM + CP) / 3 = (2.90 + 3.27 + 4.10) / 3 ≈ **3.42 万元**
- **结论**：成本区间 **2.9 ~ 4.1 万元**，预期值约 **3.3 ~ 3.4 万元**。

## 4. 成本预算与成本基线

**分配方式**：采用「**分配资源成本**」（按资源费率计算，教材 §6.5），按 WBS 阶段把总成本分摊到各时间段的阶段完成点，形成成本基线。

**成本基线表**（间接成本按 DHC 比例分摊，系数 = 32,730 / 28,200 ≈ 1.161）：

| 阶段 | 工时(人时) | DHC(元) | 含间接后成本(元) | 累计成本(元) | 累计占比 | 计划完成点 |
|---|---|---|---|---|---|---|
| 需求分析 | 32 | 3,200 | 3,714 | 3,714 | 11.3% | M1（10/14） |
| 系统设计 | 30 | 3,000 | 3,482 | 7,196 | 22.0% | M2（10/21） |
| 编码实现 | 124 | 12,400 | 14,392 | 21,588 | 66.0% | M3（11/23） |
| 测试 | 36 | 3,600 | 4,178 | 25,766 | 78.7% | M4（12/09） |
| 部署与交付 | 20 | 2,000 | 2,321 | 28,087 | 85.8% | M5/M6（12/14~12/16） |
| 项目管理 | 40 | 4,000 | 4,642 | 32,729 | 100% | M7 提交（12/19） |
| **合计** | **282** | **28,200** | **32,729** | | | |

## 5. 成本控制与变更

- **监控依据**：以本成本基线为参照，在 [[第13章 项目跟踪与度量]] 中按阶段记录实际投入，计算偏差（CV = EV − AC）。
- **变更联动**：任何需求/WBS 变更须同步评估工作量与成本影响，更新本预算与基线（教材 §6.5：变更时需同步变更预算）。
- **超支处置**：若某阶段实际成本超基线，需分析原因（估算偏差 / 范围蔓延 / 效率问题）并在复盘时更新估算参数。
- **跟踪载体**：实际成本记录见「成本管理 / 实际成本记录」（待补）。
