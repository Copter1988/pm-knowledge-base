## 三、访问方式

克隆仓库到本地：

```bash
git clone https://github.com/Copter1988/pm-knowledge-base.git
```

进入后按 `项目维护手册.md` 的「重新上手」一节即可配置并运行：

```bash
mvn -s mvn-settings.xml spring-boot:run
```

> 说明：GitHub 直连可能受网络环境影响，若克隆或推送失败，需启用代理后重试。

## 四、权限说明（重要，需甲方确认）

- 若仓库为**公开**：甲方（老师）可直接通过上述地址访问全部内容，无需账号。
- 若仓库为**私有**：需甲方提供一个 GitHub 账号，由我方将该账号添加为 collaborator 并**开通最大权限**（可读、可写），以便查看与下载全部代码和文档。

> **待确认项**：① 仓库当前可见性为「公开」还是「私有」；② 若为私有，甲方的 GitHub 账号是什么。
