# 附录B 课程知识图谱

> 本附录以「知识图谱」的形式概括全书结构与重点内容，逐章列出关键知识点，并标注知识之间的 include（包括）与 next（接下来的内容）关系，是全书的速览地图。

## 图谱总览

- 图谱用图的形式概括全书结构及重点内容，其中 **include** 意为「包括」，**next** 意为「接下来的内容」。
- 知识图谱覆盖全书前四篇共 **16 章**（第 1 章～第 16 章），第 17 章为项目实践篇，不在知识图谱范围内。

**总体图谱（软件项目管理 → 四个阶段）**：

| 阶段 | 归属篇章 | 章节 |
| --- | --- | --- |
| 项目初始（引言） | 第一篇 | 第 1 章 软件项目管理概述、第 2 章 项目立项与招投标 |
| 项目计划 | 第二篇 | 第 3～12 章（生存期模型、需求管理、任务分解、成本、进度、质量、配置管理、团队、风险、合同计划） |

| 项目结束 | 第四篇 | 第 16 章 项目结束过程 |

> 第二篇「项目计划」的知识图谱自上而下依次为：软件项目生存期模型 → 软件需求管理 → 软件项目任务分解 → 软件项目成本计划 → 软件项目进度计划 → 软件项目质量计划 → 软件项目配置管理计划 → 软件项目团队计划 → 软件项目风险计划 → 软件项目合同计划（其间以 next 关系衔接）。
